# Launchpad: מרכז ניהול הקמה (דמו)

דמו של כלי לניהול הקמת אתרים וסוכני AI, מנקודת המבט של מנהל פרויקט: מהרגע שהאפיון והעיצוב נסגרו ועד העלייה לאוויר.
כל הלקוחות, האנשים והנתונים בדויים.

## הרצה מקומית
אין שלב בנייה ואין תלויות.
- **הכי פשוט:** פותחים את `index.html` בדפדפן בלחיצה כפולה.
- **עם שרת מקומי:** מריצים `python3 -m http.server 8000` מתוך התיקייה ופותחים את `http://localhost:8000`.

## פריסה ב-Vercel, עם העוזר מחובר ל-Claude (מומלץ)
כך מי שמקבל את הקישור יכול לשאול את העוזר שאלות אמיתיות בלי להביא מפתח משלו. המפתח שלך יושב בשרת של Vercel ולא מגיע לדפדפן.

1. **יוצרים מפתח ייעודי לדמו** ב-console.anthropic.com ← API Keys. מומלץ מפתח נפרד, כדי שאפשר יהיה לבטל אותו בלי לפגוע בשום דבר אחר.
2. **מגדירים תקרת הוצאה** ב-console.anthropic.com ← Settings ← Limits (למשל 10 דולר לחודש). זו ההגנה החשובה ביותר, כי הקישור פתוח לכל מי שמקבל אותו.
3. **מעלים את הקוד ל-GitHub** (ריפו חדש, מעלים את כל התיקייה כמו שהיא).
4. **ב-vercel.com:** ‏Add New ← Project ← בוחרים את הריפו ← Deploy. אין צורך לשנות הגדרות build.
5. **מוסיפים את המפתח:** בפרויקט ב-Vercel ← Settings ← Environment Variables:
   - `ANTHROPIC_API_KEY` = המפתח (חובה)
   - `ANTHROPIC_MODEL` = מודל אחר, אם רוצים (רשות. ברירת מחדל: `claude-sonnet-5-5`)
   - `RATE_LIMIT` = כמה בקשות מותרות לגולש ב-10 דקות (רשות. ברירת מחדל: 20)
6. **פורסים מחדש:** ‏Deployments ← שלוש הנקודות ליד הפריסה האחרונה ← Redeploy. משתני סביבה נכנסים לתוקף רק בפריסה חדשה.
7. **בודקים:** פותחים את הקישור. למעלה צריך להופיע "מחובר ל-Claude" בירוק. אפשר גם לפתוח את `/api/chat` בדפדפן ולראות `"available":true`.

**מה קורה כשמשהו לא עובד:** אם המפתח לא מוגדר, העוזר עובד במצב דמו. אם המכסה נגמרה או שהשרת לא זמין, הכפתורים המוכנים מחזירים תשובת דמו מסומנת, ושאלה חופשית מקבלת הודעה ברורה בעברית. גולש יכול תמיד להדביק מפתח אישי בהגדרות, והוא גובר על השרת.

### פריסה בלי שרת (Netlify / GitHub Pages)
גוררים את התיקייה ל-app.netlify.com/drop, או מפעילים GitHub Pages. העוזר יעבוד במצב דמו, או עם מפתח אישי שהגולש מדביק.

## איפה עורכים מה
| מה | קובץ | הערות |
|---|---|---|
| **נתוני הלקוחות** (4 הפרויקטים) | `js/data.js` ← `PROJECTS` | תאריכים כתובים כהיסט בימים מהיום (`launchIn: 2` = בעוד יומיים) |
| שמות השלבים (פנימי / ללקוח) | `js/data.js` ← `STAGES` | |
| ספי ההתראות החכמות | `js/data.js` ← `ALERT_RULES` | למשל אחרי כמה ימים בלי קשר מתריעים |
| **ה-system prompts** | `js/prompts.js` ← `SYSTEM_PROMPTS.internal` / `.client` | |
| כפתורי הקיצור ומה שהם שולחים | `js/prompts.js` ← `SHORTCUTS` | |
| תשובות מצב דמו | `js/prompts.js` ← `DEMO_ANSWERS` | רובן נבנות מהנתונים; "חלץ משימות" והמייל ללקוח האדום נמצאים ב-`data.js` (`demoTasks`, `demoEmail`) |
| **אילו שדות הלקוח רואה** (וגם ה-AI שלו) | `js/ai.js` ← `toClientView()` | רשימה לבנה |
| חוקי ההתראות עצמם | `js/logic.js` ← `computeAlerts()` | |
| מודלי ברירת המחדל (מפתח אישי) | `js/ai.js` ← `DEFAULT_MODELS` | אפשר לשנות גם מתוך מסך ההגדרות |
| פונקציית השרת (Vercel) | `api/chat.js` | המודל, הגבלת הקצב ומגבלות הקלט. ה-system prompts נלקחים מ-`js/prompts.js`, כך שעורכים אותם במקום אחד |
| טקסטי מסמך האפיון (מסך 3) | `js/app.js` ← `SPEC_DOC` | |
| צבעים ופונטים | `css/styles.css` ← `:root` | |

## חיבור ל-AI
לוחצים על גלגל השיניים, בוחרים Claude או OpenAI ומדביקים מפתח. המפתח נשמר רק ב-localStorage של הדפדפן ולא נמצא בקוד. בלי מפתח העוזר עובד במצב דמו, והמצב מסומן בבירור.
> בפריסה ב-Vercel העוזר מחובר דרך השרת: הדפדפן שולח רק את מזהה הפרויקט והשאלה, והשרת בונה את ההקשר. במסך הלקוח הסינון (`toClientView`) רץ בשרת. מפתח אישי, אם מדביקים אותו, נשלח ישירות מהדפדפן לספק.

## מבנה
```
index.html        המעטפת: סרגל עליון, אזור התוכן, צ'אט, מודאל
css/styles.css    כל העיצוב (RTL, רספונסיבי)
js/data.js        נתוני הדמו
js/utils.js       תאריכים יחסיים, Markdown בסיסי, אחסון
js/logic.js       שלב נוכחי, התראות חכמות, אישורים ושאלות מהפורטל
js/prompts.js     system prompts, קיצורים, תשובות דמו
js/ai.js          בניית ההקשר וסינון + קריאות ל-Claude/OpenAI
js/chat.js        רכיב הצ'אט הצף
js/app.js         ניתוב ורינדור שלושת המסכים
api/chat.js       פונקציית שרת ל-Vercel: מפתח מהסביבה, בניית הקשר וסינון בשרת, הגבלת קצב
vercel.json       מצרף את קבצי js/ לפונקציית השרת
```
